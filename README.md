# 💸 Payday Live

**Make every second of your workday feel rewarding.**

Payday Live is a customizable, browser-based earnings tracker that turns time worked into a live earnings counter. Users can set their monthly income and work schedule, manually start or pause a session, and create personalized reward milestones (like earning enough for a cookie or coffee).

## Features

- **Live earnings tracker** — an animated total that updates as time passes
- **Custom salary and schedule** — set monthly salary, currency, shift hours, breaks, and working days
- **Start / Stop / Reset** — control a work session manually
- **Treat goals** — add personalized milestones with progress bars and unlock celebrations
- **Two themes** — minimal dark and cheerful pastel
- **Three languages** — Chinese, English, and Spanish
- **Focus mode** — fullscreen distraction-free view
- **Persistent settings** — preferences and session state saved in your browser's local storage

## How it works

The app estimates your earnings using your monthly salary, configured working days per month, and paid shift duration. Starting a session increments your simulated earned total using elapsed time. Reward milestones unlock once your tracked earnings reach each goal.

**Note:** The tracker is a motivational estimate, not payroll software. A manual session may continue counting until paused, including outside your scheduled hours.
